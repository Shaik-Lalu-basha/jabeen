# 🎂 Two Hearts • One Beautiful Date

A cinematic birthday surprise website built with pure HTML, CSS and JavaScript.

## Folder structure

birthday-surprise/
├── index.html
├── style.css
├── script.js
├── images/
│   ├── mother-daughter-01.jpg
│   └── mother-daughter-02.jpg
└── music/
    └── birthday.mp3   (optional)

## Run

1. Keep the folder structure exactly as shown.
2. Double-click `index.html`, or open the folder in VS Code.
3. For the best experience, use Chrome.
4. Optional: put a birthday MP3 at `music/birthday.mp3`.

## Add more photos

Copy your photos into `images/`, then edit `script.js`.

Find:

const photos = [
  "images/mother-daughter-01.jpg",
  "images/mother-daughter-02.jpg",
];

Add:

"images/photo-03.jpg",
"images/photo-04.jpg",

etc.

## Customize

The main text is in `index.html`.
The colors and visual theme are at the top of `style.css`.
The gallery list and animation logic are in `script.js`.

No backend, database or installation is required.
